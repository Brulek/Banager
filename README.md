# Canager

把 Mac 上用命令行装的东西管起来。A friendly manager for everything you installed from the terminal — Homebrew, npm, pipx, uv, cargo, Ollama models and AI CLIs — built for people who don't want to learn the commands.

Status: design approved 2026-09-17, implementation not started. See `docs/superpowers/specs/2026-09-17-canager-design.md`.
